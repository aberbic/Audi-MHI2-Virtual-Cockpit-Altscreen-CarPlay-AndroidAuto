# CarPlay route metadata — unstable research

**Do not install this as a working integration.** The last vehicle experiment received genuine Apple Maps maneuvers but later disconnected and failed to reconnect. Stock iAP2 plus a manual MMI restart recovered it. Normal CarPlay/AA map projection does not require this adapter.

The [offline follow-up](../../docs/CARPLAY-NAVIGATION-OFFLINE-2026-10-02.md) found receive-pool-empty reports after the six guidance messages, confirmed why the outer callback cannot repair ownership by changing its return value, and mapped the available MU1438 presentation interfaces. No ownership fix or display publisher has been implemented; the adapter remains unsafe to treat as a working release.

Included sources:

- `rgd_wire.*`: bounded complete-message parsing and capability construction.
- `rgd_monitor.*`: passive link/CSM framing, negotiated session tracking, checksums, fragmentation and sequence handling.
- `rgd_packet.*`: exact MU1438 packet-buffer adaptation with size checks.
- `driver_probe.c`: load/delegate to a separately preserved original driver using stock-compatible loader flags.
- `rgd_adapter.c`: opt-in capability declaration, receive observation and subscription; no BAP/display output.
- `request_guidance.c`: single request through the existing stock client API; not a general replay tool.
- `rgd_state.*`: offline-only bounded route cache and current-maneuver selector; not linked into the adapter or any release binary.
- `test_state.c`: synthetic route/lifecycle, UTF-8, bounds and transactional-update tests.
- `test_ownership_model.py`: abstract dispatch/waiter ownership invariants, not native driver emulation or a buffer-reclamation patch.
- Fixtures and tests for malformed inputs, the observed rejection, loader delegation, callback timing and concurrency guards.

Latest code fixes the observed early-authentication request and duplicate-send race. **Those changes are isolated-test validated only, not live lifecycle validated.** Full route state, current-maneuver selection, reliable ETA/distance delivery, teardown and disconnect/reconnect remain open.

```sh
bash experimental/metadata/test.sh
bash experimental/metadata/build.sh
```

Builds stay in ignored `out/`; they do not connect to a vehicle or modify flash. There is intentionally no public one-command experimental deployment script. The library depends on exact MU1438 internal layouts and a separately preserved original driver. Review the implementation and the [handoff](../../docs/DEVELOPMENT.md) before any future parked test. Retain an independent stock restore method.

## Offline state prototype

`rgd_state_reset` starts an explicit component/session/route epoch. `rgd_state_apply` accepts complete validated route/maneuver messages for that identity, and `rgd_state_current` copies a candidate only when the first ordered maneuver has a known type and the route is eligible. Data for another identity cannot modify the cache. Caller access must be serialized.

Properties tested:

- Detail-before-list and list-before-detail; no fallback to a later cached turn when the first slot is missing.
- Partial deltas preserve absent fields, explicit empty text/lists clear them, and a current-index change clears the previous turn's distance.
- Signed 16-bit exit angles, bounded UTF-8 strings and atomic rejection of malformed/oversized supported fields.
- Sixteen associative cache slots, including large 16-bit maneuver indexes; listed slots are not evicted for unrelated prefetch data.
- Explicit session/route resets, no-route/arrival cleanup, conservative reroute invalidation and unsupported-source withdrawal.
- 20,000 generated byte inputs and 1,000 structured route sequences under host address/undefined-behavior sanitizers.

This is a conservative **presentation-candidate prototype**, not a complete protocol implementation. Only route states 1 and 6 offer candidates; intermediate/unknown states suppress them. It does not debounce route end, map maneuver types to BAP symbols, decode lanes, convert ETA/time zones or distance sentinels/units, perform timeout expiry, create route epochs from transport events, or send anything to HMI. Those policies need independent tests before integration. In particular, caller-provided epochs and freshness must come from a real lifecycle controller; simply supplying a constant token is not reconnect safety.

The ownership model checks only that an observer does not acquire a buffer, completion returns it once, and a reply waiter retains ownership until its own release. Unknown ownership evidence fails the model rather than guessing. It contains no mapping of native error codes to ownership transitions. A future native repair must establish that mapping independently; passing this model does not validate it.

Validation on 2026-10-02: full macOS host suite passed, metadata tests passed in Linux Docker (the emulator printed its usual sanitizer thread-register warnings), and the reducer compiled with the QNX 6.5 toolchain. No generated object or test executable was run on the vehicle. The existing `build.sh` still excludes `rgd_state.c`; the driver, map runtimes and release artifacts are unchanged.

The opt-in marker used by the code is `/mnt/app/root/mu1438-rgd/metadata.enabled`. Do not create it during normal installation. Recording may include road names and route text in `/tmp/mu1438-rgd-metadata.log`; those are private. The default package does not install this library or marker.

The [Luka reference](https://github.com/luka-dev/mib2q-carplay-rgi) documents metadata support from Apple/Google Maps and lack of it from Waze in its testing. App behavior is not interchangeable with availability of cluster map video. The Qualcomm attachment and renderer cannot simply be loaded on Tegra.
